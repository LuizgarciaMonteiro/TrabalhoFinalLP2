## 📝 Descrição

O projeto acadêmico **SistemaChamadosHelpDesk** é uma solução robusta desenvolvida inteiramente em **Java** para o gerenciamento de chamados e suporte técnico. O objetivo do sistema é facilitar a abertura, acompanhamento e resolução de tickets de suporte, organizando o fluxo de trabalho entre usuários e técnicos.

## 🚀 Funcionalidades Principais

* **Abertura de Chamados:** Registro de incidentes com prioridade e descrição.
* **Gerenciamento de Status:** Controle de fluxo (Aberto, Em Andamento, Finalizado).
* **Cadastro de Usuários:** Gestão de clientes e técnicos.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java (JDK 21)
* **IDE Recomendada:** VS Code / IntelliJ IDEA / Eclipse
